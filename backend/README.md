# Backend (Supabase)

โฟลเดอร์นี้เก็บ **Supabase Edge Functions** และไฟล์ที่เกี่ยวกับ backend ของโปรเจกต์

- `supabase/` — ฟังก์ชัน Edge (`supabase/functions/`) และ config ของ Supabase CLI

## คำสั่งที่ใช้จากรากโปรเจกต์

```bash
npm run supabase:link
npm run supabase:deploy
```

หรือเข้า `backend` แล้วรัน Supabase CLI โดยตรง (โฟลเดอร์ `supabase` อยู่ภายใต้ `backend/`)
